# 📌 About StudySathi

**StudySathi** is a modern **Study Management Web Application** designed to help students organize their academic activities in one place.

It provides a centralized environment where students can manage their:

- 📚 Subjects
- ✅ Tasks
- 📝 Study Notes
- ⏱️ Study Sessions
- 📊 Academic Progress

StudySathi combines task management, subject organization, note-taking, study timing, and progress tracking into a single dashboard.

The application is developed using **HTML5, CSS3, and JavaScript ES6+** and uses the browser's **Local Storage API** for client-side data persistence.

---

# 🎯 Project Objectives

The main objectives of StudySathi are:

- To provide students with a simple platform for organizing academic activities.
- To help students manage tasks and deadlines efficiently.
- To provide a dedicated environment for study notes.
- To track focused study sessions and total study time.
- To visualize study progress through a centralized dashboard.
- To provide a responsive and user-friendly interface.

## 💾 Local Storage

StudySathi uses the browser's **Local Storage API** to store application data.

The following information can be persisted:

- Tasks
- Subjects
- Notes
- Study sessions
- Timer statistics

This allows the application to preserve data even after refreshing the browser.

> **Note:** Local Storage is specific to the browser and device being used.

---

## 📤 Data Import & Export

StudySathi provides a simple backup mechanism through JSON files.

### Export

Users can export their StudySathi data as a JSON file.

### Import

Previously exported data can be imported back into the application.

This makes it possible to create personal backups of:

- Tasks
- Subjects
- Notes
- Study sessions
- Timer statistics
