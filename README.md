# 📌 About StudySathi

**StudySathi** is a modern and interactive **Study Management Web Application** designed to help students organize their academic activities in one centralized platform.

Instead of managing tasks, subjects, notes, and study sessions separately, StudySathi brings these activities together into a single and easy-to-use dashboard.

The application allows students to:

* 📚 Manage academic subjects
* ✅ Create and track study tasks
* 📝 Manage study notes
* ⏱️ Track focused study sessions
* 📊 Monitor study progress
* 💾 Store information locally
* 📤 Export and import study data

StudySathi is built using **HTML5, CSS3, and JavaScript ES6+** and uses the browser's **Local Storage API** for client-side data persistence.

The main objectives of StudySathi are:

Provide useful statistics and progress information through the dashboard.

Provide a dedicated study timer for focused study sessions.

### 5. Simplify Note Management

Allow students to create, edit, search, and organize their study notes.

### 6. Provide a Responsive Experience

Make the application accessible across desktop, tablet, and mobile devices.

# 💾 Data Storage

StudySathi uses:

```text
Browser Local Storage
```

for storing application data.

### Stored Information

```text
Tasks
Subjects
Notes
Study Sessions
Timer Statistics
```

### Benefits

* No backend database required
* Simple setup
* Fast local access
* Works with static hosting
* Data remains after page refresh

> **Important:** Local Storage data belongs to the specific browser and device. Clearing browser storage can remove the saved StudySathi data.

---

# 🔐 Privacy

StudySathi is primarily a client-side application.

Study data is stored locally in the user's browser and is not automatically transmitted to a remote backend server.

For important information, users are encouraged to periodically export their data and keep a backup.

# 🚀 GitHub Pages Deployment

StudySathi can be hosted directly using GitHub Pages.

### Steps

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
6. Save the settings.
7. GitHub will generate a public deployment URL.

### Example

```text
https://pokhrelsamir.github.io/StudySathi/
```
